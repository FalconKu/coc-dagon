# 大衮：深潮之下

《克苏鲁的呼唤》7 版短冒险。改编自 H. P. 洛夫克拉夫特 1919 年发表的公版短篇《大衮》（Dagon）。

> 1918 年春，一名从太平洋上被救回的商船二副写下二十七天的手稿后跳了楼。他说海退开了，露出一片不该存在的泥滩。你手上现在有他写到一半的稿纸。

- **人数**：3 人（2–5 人可调）
- **时长**：约 3 小时
- **结构**：5 章 / 32 节点 / 4 结局
- **推荐世界**：`pacific_shoal`（配套资源包 [深潮档案：太平洋异滩](../coc-dagon-shoal)）

## 结构

| 章 | 内容 | 关键选择 |
|---|---|---|
| 一、教会街 | 公寓现场，三个访客先到 | 追德国人 / 拦沃斯 / 留下读稿 |
| 二、九个人 | 医院、海关、酒馆、教堂、学会 | 二选一：乔纳斯或凯恩 |
| 三、出航 | 租船、十九天航行、第一次测深 | 三条船 |
| 四、泥滩 | 海退开、独石柱、裂谷 | 拓片 / 读刻文 / 下裂谷 |
| 五、那一夜 | 守夜、目击、逃生、回程 | 留在泥滩 / 回甲板 / 躲小艇 |

四个结局：**写下来**（原作结局）、**封存**、**公开**、**再去一次**。

## 与原作的关系

《大衮》原作是一篇第一人称手稿：海员被德国袭击舰俘获、夺艇逃走、在太平洋漂流、海底泥滩升起、独石柱与刻文、夜间巨物环抱石柱、被救后精神崩溃、写下记录后自尽。

本冒险保留了全部核心情节，但把叙述者变成「玩家要调查的死者」，玩家从旧金山开始，沿着他留下的痕迹走到他自己去过的地方。

三处有意的改动：

1. **视角**：原作是当事人回忆，本作是第三方调查。这样玩家才有得选。
2. **九个人**：原作只有叙述者一人。本作加了一条「九人被放走、只回来一个」的线，用来解释「他为什么被放回来」。这是最大的原创部分，也是驱动调查的引擎。
3. **结局**：原作只有一个（自杀）。本作给了四个，其中 `ending_manuscript` 就是原作结局，玩家可以主动选择它。

## 守秘人须知

包内 `content/lorebooks/dagon-gm-guide.json` 有 12 条守秘人指引，全部为 GM-only（`visible_to: []`），包括：

- 五章的时间分配（180 分钟怎么切）
- 大衮的三条演法铁律（不追人、不可伤害、恐怖来自规律）
- 六个 NPC 的说话方式
- 线索矩阵（每条结论给三条独立线索，避免卡死）
- 四个结局的分量（不要暗示哪个「更对」）
- 接续集的三条线

最重要的一条：**不要让大衮追杀玩家**。它不朝任何人看，它的行为是完全重复的。恐惧来自「每一次都一样」，不来自体型。

## 理智检定点

包内已给出建议数值（`gm:san.loss`），按位置分档：

| 位置 | 成功 | 失败 |
|---|---|---|
| 甲板（四百码） | 0 | 1d6 / 1d8 |
| 泥滩（一百码） | 1 | 1d6 / 1d10 |
| 小艇（三十英尺仰视） | 1 / 1d8 | 1d10 / 1d100 |

数值为按 CoC 7e 通用格式自设，非规则书原文。
